Logo IzaIA — fichiers et usages

Les lettres sont converties en tracés : aucune police n'est requise pour afficher ou imprimer ces fichiers. Le « IA » est en italique, dans le brun laiton de la charte, comme sur le site.

Version couleur

L'usage par défaut, sur fond clair : papier à en-tête, devis, présentations, signature de courriel.

Monochromes

Le noir pour tout ce qui n'a qu'une encre — tampons, fax, photocopies, documents administratifs. Le blanc pour les fonds sombres et les photographies.

Sur fond noir intégré

Le fond fait partie du fichier. Pratique pour une bannière ou un encart ; à éviter sur un support dont le fond n'est pas noir.

Symbole seul

Pour les usages où le nom est déjà présent ou l'espace trop réduit : favicon, avatar, filigrane, tampon.
